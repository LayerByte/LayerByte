# LayerByte Developer Portfolio (Pure HTML, CSS, JS Edition)

A modern, responsive, high-performance developer portfolio website for **LayerByte**, built entirely with **pure HTML5, CSS3, and modern Vanilla JavaScript**.

Features LayerByte's signature **Electric & Deep Blue** color palette (`#3977da`, `#065ec0`, `#86a6d5`, `#ffffff`), interactive starry particle canvas, 3D card tilt, systems skillsets, and projects from [github.com/LayerByte](https://github.com/LayerByte).

## 🚀 Quick Start

### 1. View Directly in Browser
You can simply double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Safari).

### 2. Run via Local Server (Recommended)
If you have Python installed:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

Or with Node.js:
```bash
npx serve .
```

## 🌐 Free Deployment Options

- **GitHub Pages**:
  1. Push this folder to your repository at `github.com/LayerByte/<repo>`.
  2. Go to **Settings** > **Pages** > Select `main` branch `/ (root)` > Save.
  3. Your portfolio is live with a free `https://layerbyte.github.io` URL!
- **Vercel / Netlify**:
  - Drag and drop this folder into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant global edge deployment.
